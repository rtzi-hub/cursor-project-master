# Existing-project workflow

1. Describe the requested change.
2. Capture the Git/test baseline.
3. Use Cursor Ask Mode for read-only discovery.
4. Refine `AGENTS.md` from verified repository behavior.
5. Use Plan Mode for blast-radius analysis.
6. Approve the smallest compatible plan.
7. Use Agent Mode for implementation.
8. Run regression verification.
9. Run security checks.
10. Review and launch.
