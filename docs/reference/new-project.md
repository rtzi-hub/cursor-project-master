# New-project workflow

1. Describe the idea.
2. Use the Architecture Coach in an AI chat.
3. Approve requirements and architecture.
4. Produce `cpm.project.json`.
5. Run the repository-aware Doctor.
6. Generate/refine `AGENTS.md` and scoped Cursor rules.
7. Build a phased TODO.
8. Scaffold the approved structure.
9. Implement one phase at a time.
10. Verify, secure, and launch.

Project-specific `AGENTS.md` comes after architecture approval so it can encode real boundaries instead of guesses.
